CODECAMPUS — CSE STUDENT BLOG
================================

WHAT IS THIS?
A beginner-friendly, responsive blog website starter project for a 5th semester
Computer Science and Engineering student. It uses HTML, CSS and JavaScript.
No installation, database or paid service is required to run it locally.

HOW TO OPEN IN VISUAL STUDIO CODE (MAC)
1. Download and extract codecampus-cse-blog.zip.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the extracted folder named "codecampus-cse-blog".
5. Open index.html.
6. Right-click inside index.html and choose "Open with Live Server"
   if you have the Live Server extension installed.
   OR open the folder in Finder and double-click index.html to view it
   in your browser.

RECOMMENDED VS CODE EXTENSION
Live Server — Ritwick Dey
In VS Code, open Extensions (four squares icon), search for "Live Server",
and install it. Then click "Go Live" at the bottom of VS Code.

PROJECT FILES
index.html       Main website structure and page sections
css/style.css    Colours, layout, responsive design and styling
js/posts.js      Sample blog posts and article content
js/main.js       Search, category filters, article popup and mobile menu

HOW TO CHANGE THE BLOG NAME
In index.html, search for "CodeCampus" and replace it with your chosen name.

HOW TO CHANGE YOUR INTRODUCTION
In index.html, find the section with id="about" and edit the sample text.
Replace "5th semester" or other details if they do not match you.

HOW TO ADD OR EDIT BLOG POSTS
1. Open js/posts.js.
2. Copy one complete post object (from { to },) inside the posts array.
3. Give the new post a unique id number.
4. Change category, date, readTime, title, excerpt, art, symbol, artLabel and content.
5. Save the file and refresh your browser.

Available categories: "Core CS", "Programming", "Student Life".
Available art values: "network", "java", "study".
Keep the content property inside backticks (`...`) because it contains HTML.

IMPORTANT FOR YOUR COLLEGE REPORT
- Personalise the name, introduction and sample posts.
- Verify every technical explanation using your prescribed textbooks and notes.
- Take your own screenshots while running and testing the website.
- Mention the technologies you actually used. This project uses HTML, CSS and
  JavaScript. It does not currently use Blogger or Google Analytics.
- This is a local website on your computer. To make it publicly accessible,
  you will need to publish/host it using a service such as GitHub Pages.
  A local preview is not yet a live public website.
